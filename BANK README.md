# Bank Network Project

## Overview

This project is a simulated bank network designed and configured in Cisco Packet Tracer.

The network connects:

- Branch 1
- Headquarters / Data Center
- Branch 2

The network includes routers, switches, servers, computers, laptops, and printers.

## Network Topology

The network uses OSPF to provide dynamic routing between the different network locations.

### Main Components

- Cisco Routers
- Cisco Switches
- PCs
- Laptops
- Network Printers
- DNS Server
- Web Server
- Database Server

## Technologies Used

- VLANs
- Inter-VLAN Routing
- OSPF
- DHCP
- DNS
- ACLs
- SSH
- Port Security
- IP Addressing and Subnetting

## Network Locations

### Branch 1

Branch 1 provides network access to users, laptops, and printers.

### Headquarters / Data Center

The Data Center hosts:

- DNS Server
- Web Server
- Database Server

### Branch 2

Branch 2 provides network access to users, laptops, and printers.

## Routing

OSPF is configured to provide dynamic routing between the network locations.

## Security

Network security features include:

- Access Control Lists (ACLs)
- SSH remote management
- Switch Port Security
- VLAN segmentation

## Tools

- Cisco Packet Tracer
- EdrawMax
